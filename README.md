# CUDA High Performance Kernels

CUDA C++ based GPU kernel optimization practice.

## Environment

- GPU: RTX 5070 Laptop GPU
- CUDA: 13.1
- OS: Ubuntu 22.04 WSL


## Implemented Kernels

### Basic Kernels

- Vector Add
- Matrix Add
- ReLU


### Memory Optimization

- Coalesced Memory Access
- Shared Memory
- Bank Conflict


### Parallel Reduction

- Naive Reduction
- Shared Memory Reduction
- Warp Shuffle Reduction


### Matrix Computation

- Naive GEMM
- Tiled GEMM
- cuBLAS Comparison


### Asynchronous Execution

- CUDA Stream
- Pinned Memory
- Async Copy
