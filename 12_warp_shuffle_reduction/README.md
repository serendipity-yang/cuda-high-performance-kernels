# Warp Shuffle Reduction


## 1. Problem


This experiment implements parallel reduction on GPU.


Given an input array:


```text
input[0...N-1]
```


the goal is to calculate the sum of all elements.


Reduction is a fundamental operation in deep learning operators, such as:


- Softmax
- LayerNorm
- Attention


---

## 2. Baseline


The naive reduction assigns input elements to CUDA threads.


Each thread loads data and performs partial summation.


However, the naive implementation has several limitations:


- High global memory access overhead
- Frequent synchronization
- Low utilization of GPU parallelism


---

## 3. Optimization


## Warp Shuffle Reduction


CUDA provides warp-level primitives:


```cpp
__shfl_down_sync()
```


which allow threads inside the same warp to exchange register values directly.


Compared with shared memory communication:


- No shared memory access required
- No synchronization inside a warp
- Lower communication overhead


The reduction process:


```text

Thread values

        |
        v

Warp-level shuffle reduction

        |
        v

Warp partial sum

        |
        v

Block reduction

```


---

## 4. Implementation


Files:


```text
warp_shuffle_reduction.cu

multi_block_reduction.cu
```


### warp_shuffle_reduction.cu


Implements warp-level reduction using:


```cpp
__shfl_down_sync()
```


The function allows threads within the same warp to exchange register values directly.


### multi_block_reduction.cu


Handles reduction across multiple CUDA blocks.


Each block calculates a partial sum, and the final result is accumulated to obtain the complete reduction result.


---

## 5. Kernel Design


CUDA configuration:


```text
Threads per block:

256
```


A warp contains:


```text
32 threads
```


Therefore:


```text
256 / 32 = 8 warps per block
```


Each block contains 8 warps for parallel execution.


The input elements are divided among multiple blocks:


```text

Grid

|
|---- Block 0
|       |
|       threads
|
|---- Block 1
|       |
|       threads
|
|
|---- Block N

```

## 8. Key Learning


- A warp consists of 32 CUDA threads and executes instructions in SIMT fashion.
- `__shfl_down_sync()` enables direct register data exchange between threads inside a warp.
- Warp shuffle reduction reduces the overhead of shared memory communication.
- Shared memory reduction can be further optimized by replacing the last warp-level operations with shuffle instructions.
- Multi-block reduction requires combining partial sums generated by different blocks.
